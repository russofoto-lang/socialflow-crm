# Features

## Gia disponibili
- Login con Supabase Auth.
- Protezione route per ruolo.
- Dashboard Admin.
- Gestione clienti.
- Gestione contenuti.
- Filtri contenuti per cliente, stato, tipo, piattaforma e data.
- Board stile Trello con cambio stato tramite select.
- Calendario editoriale mensile.
- Area Cliente con contenuti collegati al proprio cliente.
- Approvazione contenuti.
- Richiesta modifiche con commento.
- Commenti per contenuto.
- Upload file contenuto tramite Supabase Storage.
- Database Supabase reale.
- Seed demo.
